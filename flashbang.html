Game Overview

游戏简介

《Afterflash / 余闪》是一款第三人称科幻动作潜入游戏，围绕“失去稳定光源后，城市如何被重新定义”展开。玩家通过主动制造闪光、噪声与短时混乱，在危险区域中打出属于自己的通路。

World Setup

故事与氛围

在一次大规模轨道事故后，城市供能系统持续崩坏。失控的安保网络将黑暗区域视为“异常”，而幸存者开始把灯光本身当成一种危险信号。你所在的小队需要潜入这些被切断的高层街区，寻找消失的数据与人。

近未来都市 动作潜入 环境叙事 高密度遭遇战
光源博弈

闪光弹、故障灯、临时电路会直接改变敌我视野和移动路线。

声音导航

脚步、设备电流与环境警报不仅是氛围，也会改变敌人巡逻逻辑。

多路径推进

正面破阵、绕行潜入、短时爆发撤离，都能构成有效解法。

短线叙事

每个关卡都保留独立主题与人物痕迹，避免剧情只存在于文档里。

Combat Loop 侦察 → 造势 → 破口 → 脱离

战斗不是“进入房间然后清场”，而是围绕信息差与短时窗口展开。

Playable Slice 15 分钟垂直切片

包含一段外墙潜入、两次巡逻交错遭遇，以及一次小队撤离选择。

Target Feeling 紧张、明快、压迫但不迟钝

我们追求的是高响应速度，而不是笨重的“写实迟滞”。

Dev Log

开发日志

这里记录最近几轮版本推进，而不是泛泛而谈的“正在努力中”。我们更关心哪些机制已经成立，哪些问题仍然没有解决，以及下一轮迭代会砍掉什么、保留什么。

2026.04 / Sprint 07

遭遇战节奏重构

将原本偏脚本驱动的房间战斗改成更依赖视野中断与短时失明反馈的动态遭遇。闪光后敌方恢复逻辑被重新拆分，读秒感更清晰。

  • 调整了闪光弹命中后的 AI 失衡时长与音效层级。
  • 重做一段废弃中继站关卡，使逃离路线更立体。
  • 加入危险提示色，避免纯黑环境下信息过载。
2026.03 / Sprint 06

垂直切片首次串通

首个完整流程从屋顶切入、穿越中庭再到地铁撤离已经可以连通游玩。虽然美术与剧情触发仍然粗糙，但节奏闭环初步成立。

  • 完成主循环的临时 UI 与任务提示。
  • 加入两种敌方职业，观察型与追击型行为差异更明显。
  • 把部分叙事文本改为场景内的可见证据与通讯记录。
2026.01 / Prototype

核心原型验证

这一阶段只回答一个问题：在第三人称视角下，闪光是否能成为真正的主动玩法，而不是一次性控制技能。结果是肯定的，但实现成本远高于预估。

  • 验证闪光、阴影、声音三者叠加的风险收益关系。
  • 推翻第一版慢节奏潜行方案，转向更高压的动作潜入结构。
  • 明确项目关键词：明灭、失真、压迫、反打。

Pipeline

制作管线
